# エックスサーバー初期ドメインでの検証

確認日: 2026-10-17（日本時間）。実サーバーのID・認証情報は未提供で、アップロード・設定変更・実機検証は実施していません。

## 1. 専用環境を作る

1. サーバーパネルで実際のPHP/DB/ディスク容量を確認。今回のローカル検証はPHP8.3、MariaDB10.11、WordPress7.1.3です。公式案内にはPHP8.5までの選択肢、新規DBのMariaDB10.11が掲載されていますが、契約サーバーの表示が優先です。
2. 既存サイトと別の設置先・別DBを使う。初期ドメインは利用者が確認した `https://<server-id>.xsrv.jp/` のみ使用。既存WordPressへテストデータを投入しない。
3. 作業前にDB・wp-content・wp-config.php・.htaccessをバックアップし、サーバー外へ保管。既存ファイルに上書きしない。
4. HTTPSを確認。初期ドメインでのSSLの可否・実際のURLはサーバー側で確認し、認証情報をHTTPで送信しない。
5. **インストール前にアクセス制限**を設置先全体へ適用する。サーバーパネルのアクセス制限（BASIC認証等）を利用。WordPressログインだけを保護するのではなく、画像・テーマアセット・REST・フィード・XMLサイトマップも未認証で取得できないことを別ブラウザで確認。
6. WordPress「検索エンジンがサイトをインデックスしないようにする」を有効にする。noindex/robots.txtは補助であり、アクセス制限の代替にしない。

## 2. 導入

- 管理画面「外観→テーマ→新しいテーマ→テーマのアップロード」で `shikipress-1.0.2.zip` を選び、有効化。
- 任意でwp-config.phpへ `define('WP_ENVIRONMENT_TYPE', 'staging');` を設定（重複定義をしない）。テストサイトのまま維持する。
- ShikiPress→記事自動化で四季カテゴリーの作成予定を確認し実行。衝突時は既存カテゴリーを選び対応付ける。
- デザインでロゴ・メイン文言・季節・Asia/Tokyoを確認。ナビゲーションで公開済み固定ページの役割を設定。
- 広告は「テスト」。実パブリッシャーID/トラッキングタグ/APIキーを試験用に持ち込まない。
- パーマリンクを保存し、トップ/記事/カテゴリー/固定ページ/検索/404/wp-sitemap.xmlを確認。下書き・予約・非公開・保護ページが一覧へ出ないことを確認。

## 3. サーバー固有確認

- WAF: 通常の設定保存とJSONインポートを試す。403が出たらパネルの検知ログとサポート案内で原因を確認し、保護を一括解除しない。
- Xアクセラレータ・サーバーキャッシュ: ログイン中、プレビュー、検索、管理画面を共有キャッシュ対象にしない。テーマのキャッシュ無効化はサーバー側HTMLキャッシュを消去しません。投稿公開・非公開化・設定変更後に対象URLが更新されることを確認。季節/イベントの日付境界より長いTTLにしない。境界直後にパネルから該当キャッシュを削除する運用も可能。プレビューのクエリURLを保存・共有キャッシュしない。
- URL書き換え: 管理画面で保存後の.htaccessを確認。既存のアクセス制限の設定を失わない。
- 画像: メディア画面から実際にWebP/AVIFの生成可否を確認。未対応形式を強制変換しない。JPEG/PNGも利用可能。
- 広告: ダミーの遅延/未配信/失敗状態、下部4タブ、同意表示領域、iPhoneセーフエリア、キーボードを確認。実広告は別途許可後に検証。
- メール: 本テーマは問い合わせ先を勝手に設定せず、実メールを送信しません。問い合わせページの連絡方法は運営者が用意します。

## 4. 予約投稿とCron

WP-Cronはアクセス時に起動するため、訪問が少ないと予約公開が遅れます。利用者がサーバーパネルのCronを設定する場合のみ、実際のPHPパス・実際の設置先を確認して次の形に置き換えます（パスは例です）。

```sh
/確認済みの/php /実際の非公開設定済み設置先/wp-cron.php > /dev/null 2>&1
```

5分間隔などを選び、まずテスト記事の予約・公開時刻・ログを確認します。二重起動を避けるため、サーバーCronが動作すると確認してから `DISABLE_WP_CRON` をtrueにします。WP-CLIが利用できる場合は `wp cron event list` と `wp cron event run --due-now` を対象パス指定で確認。コマンドを第三者に実行させる公開URLは作りません。
